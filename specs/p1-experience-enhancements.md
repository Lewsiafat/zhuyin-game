# feat: P1 體驗強化

- **分支:** `feat/p1-experience-enhancements`
- **日期:** 2026-04-08

## 描述

強化遊戲的互動回饋與沉浸感：答錯時顯示目標鍵高亮提示、加入 ESC/P 暫停功能、結束畫面顯示正確率與最高連擊數、每 5 關出現 Boss 關卡、等級提升時加入升級動畫。

## 任務清單

- [x] 答錯高亮提示：打錯時鍵盤上的正確目標鍵顯示高亮（黃色發光），0.8 秒後消退
- [x] 暫停功能：ESC 或 P 鍵可暫停/繼續遊戲，顯示 PAUSED overlay，限時模式計時暫停
- [x] 結束畫面統計：顯示正確率（正確次數 / 總按鍵次數 × 100%）和本局最高連擊數
- [x] Boss 關卡：每第 5 關（Lv.5, 10, 15...）派出 Boss（HP x3、體型放大 x1.5、金色外框）
- [x] 升級動畫：等級提升時在怪物區顯示「⬆ Lv.X！」閃爍文字 1 秒
