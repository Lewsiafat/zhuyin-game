# feat: P2 精緻化功能

- **分支:** `feat/p2-polish-features`
- **日期:** 2026-04-08

## 描述

四項精緻化功能：背景音樂（Web Audio API 程序生成，可靜音）、成就系統（解鎖條件型徽章）、每日挑戰（固定題組、每日一次、分數紀錄）、互動教學關卡（新手引導）。

## 任務清單

- [x] 🎵 背景音樂：Web Audio API 程序生成迴圈旋律，右上角靜音按鈕（🔊/🔇），預設靜音（用戶互動後可開啟）
- [x] 🏆 成就系統：定義 6~8 個成就條件（首殺、連擊 10、破百分、打完 Boss...），解鎖時彈出徽章動畫，localStorage 持久化
- [x] 📅 每日挑戰：以當天日期為 seed 選出固定 5 句題組，限玩一次，分數記錄於 localStorage，顯示今日最高分
- [x] 📖 教學關卡：新手模式，逐步引導認識注音鍵盤（高亮目標鍵 + 提示文字），完成後解鎖一個成就
